# Compañeros virtuales

Mascotas de escritorio en 3D low poly para Windows.

Aquí viven las versiones que la app descarga para **actualizarse sola**: ve a [Releases](../../releases)
y baja el `CompanerosVirtuales-Setup-X.Y.Z.exe` más nuevo para instalarla la primera vez.

Para publicar una versión nueva se agrega la carpeta `publicar/X.Y.Z/` (instalador en pedazos `setup.partNN`,
`sha256.txt`, `.blockmap`, `latest.yml` y `notas.md`) y el flujo *Publicar versión* crea el Release.
